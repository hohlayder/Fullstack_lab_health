# Близкие — напоминания о лекарствах для семьи

Учебный проект курса «Fullstack», первый семестр. Тема: «Напоминания о лекарствах: расписание для семьи, напоминания, отметка „принято“, печать списка для врача».

## Лабораторная работа №1

Первый этап — интерфейс и каркас frontend на React + TypeScript. Готовая библиотека UI-компонентов — Material UI; сборка — Vite; клиентская маршрутизация — React Router.

Планируемые экраны: расписание приёмов, члены семьи, лекарства, напоминания, список для врача. На этом этапе используются только демонстрационные данные. Сервер, база данных, авторизация и интеграция относятся к следующим лабораторным работам.

## Запуск

Нужны Node.js версии 22.12+ и npm. Из корня репозитория:

```powershell
cd frontend
npm.cmd install
npm.cmd run dev
```

Откройте http://127.0.0.1:5173. Для проверки сборки: `npm.cmd run build`; для проверки кода: `npm.cmd run lint`.
